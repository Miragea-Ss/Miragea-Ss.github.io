# Media Vault — Infinite Canvas entry brief

## Objective

Make a first-time visitor understand that Eliora Infinite Canvas is usable immediately without an Eliora account, while preserving the existing Miragea atmosphere and the other public routes.

## Required visitor promise

- Start the browser canvas without registration.
- Cards, connections, and boards stay in the visitor's browser by default.
- Optional local AI is available through the visitor's own Local Kit, ComfyUI, and llama.cpp.
- Optional international BYOK includes OpenRouter; no Chinese real-name-verification service is required by the core route.
- Agent actions remain review-gated by default.
- Provide working links for opening the canvas and opening its five-step guide.

## Scope and boundaries

- Edit only the Codex workspace repository.
- Preserve the current Miragea visual system, language switcher, videos, and non-canvas cards.
- Keep English as the default language and provide complete Japanese and Chinese copy.
- Do not alter or restore the former red Media Vault application.

## Acceptance checks

- The featured entry communicates all five promises in EN, JA, and ZH.
- Both calls to action resolve to Infinite Canvas with the matching supported interface language.
- The guide call to action opens the public start guide automatically.
- Desktop and mobile layouts remain readable.
- Existing build and Infinite Canvas contract tests pass.
