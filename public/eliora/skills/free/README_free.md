# MOSS 1段目 ワークフロー（無料サンプル）

`MOSS-Stage1_Workflow_free_sample.json` を ComfyUI にドラッグ＆ドロップして使います。
お手元の PC の ComfyUI で、ローカル実行します。

画面の配置は `layout-preview.png` でも確認できます。

> **これは「1段目」だけです。二段階仕上げの完全版は、有料版に入っています。**

## どんなワークフローか
MOSS-Image が、構図と空気をつくります。
保存は 1 枚です（`MODE01_…`）。

## 最初の1枚（5ステップ）
1. ComfyUI を最新にします（MOSS-Image は 0.42.0 以降）。
2. 下の「必要なカスタムノード」と「必要なモデル」を入れます。
3. JSON を読み込みます。左上の「はじめに」にも同じ手順があります。
4. ① のスイッチが **False**（文章から生成）なのを確かめ、② にプロンプトを書きます。
5. モデル名が赤いときは、手元のファイルを選び直して、**Run** を押します。

## 画面の見かた
| 色・場所 | 意味 |
|---|---|
| **黄色のノード（★）** | 触るところ（モデル、プロンプト、スイッチ、サイズ、seed） |
| 灰色のノード | 上級者向け（ステップ数、CFG）。通常は触りません |
| 青灰の小さなノード | 見えない配線（Get / Set）。触りません |
| グループ ① ② ③ | 生成方法の切替、プロンプト、画像サイズ |
| グループ ④ | モデル読み込み（MOSS） |
| グループ ⑤ | 生成して保存 |
| グループ ⑥ | 参照画像（任意） |
| グループ ⑦ | 上級者向け（通常は触らない） |

- seed は、★ サンプラー（⑤）の中にあります。初期値は毎回ランダムです。
- 参照画像から作るときは、① のスイッチを **True** にして、⑥ に画像を選びます。ご自身が権利をお持ちの画像だけを使ってください。

## 必要なカスタムノード
| ノード | 使いどころ |
|---|---|
| comfyui-moss-merge-presets | MOSS の SFT と Base の融合 |
| comfyui-easy-use | 見えない配線（Get / Set） |
| comfyui_layerstyle | 参照画像の縮小（⑥） |
| rgthree-comfy | グループのオン／オフ（⑦） |

足りないときは、ComfyUI Manager の「Install Missing Custom Nodes」で入れられます。

## 必要なモデル（`ComfyUI/models/` の下に置く）
JSON に入っている名前は制作環境のものです。名前が違うときは、ドロップダウンで選び直してください。
| 置き場所 | ファイル（JSON 内の名前） |
|---|---|
| `diffusion_models/` | `moss_image_sft_bf16.safetensors` |
| `diffusion_models/` | `moss_image_base_bf16.safetensors` |
| `text_encoders/` | `qwen3.5_9b_bf16.safetensors`（type: moss_image） |
| `vae/` | `flux2-vae.safetensors` |
| `loras/` | `feverdream-epoch-07.safetensors`、`TJFilmMoss_V1.safetensors`（LoRA A・B） |

- モデルと LoRA は同梱していません。各配布元から入手してください。
- LoRA を使わないときは、そのノードを選んで **Ctrl+B**（バイパス）にします。

## 困ったとき（FAQ）
**Q. 「Missing nodes」と出ます。**
A. 上のカスタムノードが足りません。ComfyUI Manager で「Install Missing Custom Nodes」を押し、ComfyUI を再起動してください。

**Q. モデル名が赤くなります。**
A. ファイル名が違うだけです。ドロップダウンから、手元のファイルを選び直してください。

**Q. 実行すると「メモリ不足」になります。**
A. ③ のメガピクセルを小さくしてみてください。ほかのアプリを閉じるのも効きます。

**Q. 毎回、違う絵になります。**
A. seed が毎回ランダムだからです。固定したいときは、サンプラーの seed の下を「fixed」にしてください。

**Q. 画像を商用で使えますか。**
A. 使ったモデルと LoRA の規約によります。ご自身で配布元をご確認ください。
